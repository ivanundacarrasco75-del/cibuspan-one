ACTUALIZACION V16 - FILTRO Y ORDEN POR SEMANA

PASO 1 - SUPABASE
1. Abre Supabase y entra en SQL Editor.
2. Abre el archivo incluido:
   supabase\migrations\202608140080_semanas_importacion_directa.sql
3. Copia todo, pegalo en SQL Editor y presiona Run.
4. Debe aparecer Success.

PASO 2 - REEMPLAZAR EL ARCHIVO
1. Descomprime este ZIP directamente dentro de D:\CIBUSPAN_ONE.
2. Cuando Windows pregunte, elige Reemplazar el archivo en el destino.

PASO 3 - COMPILAR Y PUBLICAR
1. Abre la terminal de Visual Studio Code en D:\CIBUSPAN_ONE.
2. Ejecuta:

   npm run build

3. Si termina correctamente, ejecuta:

   npx wrangler pages deploy dist --project-name cibuspan-one --branch main

4. Abre la app y presiona Ctrl + F5.

PASO 4 - ACTUALIZAR LAS SEMANAS
1. Entra en Facturas y pagos > Importar Excel.
2. Selecciona nuevamente APROBACION PAGOS 2026 NUEVOA.xlsx.
3. Presiona el boton para importar las facturas.
4. Las facturas existentes se actualizaran; no se duplicaran.

RESULTADO
- El filtro muestra siempre las semanas 01 a 53.
- Las facturas ya escogidas permanecen arriba.
- Debajo aparecen las facturas de la semana filtrada.
- La columna SEMANA se guarda dentro de la importacion principal.
