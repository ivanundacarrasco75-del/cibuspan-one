ACTUALIZACION V32 - PERIODO Y AGRUPACION DE DASHBOARDS

Esta actualizacion no necesita ejecutar SQL en Supabase.

1. Descomprime el ZIP.
2. Copia la carpeta src dentro de D:\CIBUSPAN_ONE.
3. Cuando Windows pregunte, elige reemplazar los archivos existentes.
4. Abre la terminal de Visual Studio Code en D:\CIBUSPAN_ONE.
5. Ejecuta:

   npm run build

6. Cuando termine correctamente, ejecuta:

   npx wrangler pages deploy dist --project-name cibuspan-one --branch main

7. Abre la app y presiona Ctrl + F5.

CAMBIOS INCLUIDOS

- Dos filtros separados: periodo analizado y agrupacion del grafico.
- Mes: permite ver semanas o dias.
- Trimestre: permite ver meses o semanas.
- Semestre: permite ver meses o trimestres.
- Ano: permite ver meses, Q1-Q4 o semestres.
- Los rangos personalizados ofrecen agrupaciones apropiadas para su duracion.
- Comercial, Produccion, Financiero y Vista piloto respetan la agrupacion elegida.
- Devoluciones calcula el porcentaje dentro de cada agrupacion.
- La agrupacion diaria usa el detalle diario real de ventas.
- La regla de vida util y la diferenciacion de periodos provisionales permanecen activas.
