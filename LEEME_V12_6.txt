CAMBIO PRINCIPAL
Se separa claramente:
1. Periodo de análisis: Semana / Mes / Trimestre / Semestre / Año / Rango personalizado.
2. Ver el periodo por: Día / Semana / Mes, con combinaciones razonables según el periodo.

EJEMPLO
Periodo: Mes > Agosto 2026
Ver por: Día
El gráfico muestra del 1 al 31 de agosto, sin incluir julio ni septiembre.

GRAFICO
- Facturación real (com_ventas_detalle).
- Devolución estimada atribuida al origen.
La devolución NO es un pronóstico futuro: usa semana_origen_inicio, que ya es la clasificación oficial del módulo Devoluciones, y conserva el día relativo dentro de esa semana para la vista diaria.

OTROS CAMBIOS

- Tabla de detalle adaptada a la escala elegida.
- Mantiene el importador PDF V12.4B.

INSTALACION
1. Descomprimir en D:\CIBUSPAN_ONE y reemplazar.
2. Ejecutar npm run dev.
3. Ctrl + F5.
4. Comercial > Ventas > Resumen debe mostrar “Análisis temporal · V12.6”.
5. Validar Agosto 2026 / Día.
6. Después de validar: npm run build
7. Verificar: findstr /s /i /c:"V12.6" dist\assets\*.js
8. Publicar: npx wrangler pages deploy dist --project-name=cibuspan-one
